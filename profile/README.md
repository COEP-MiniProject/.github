# COEP CSE MiniProject Organization

This GitHub Organization hosts private repositories for CSE department mini-projects.

## Access

| Team | Role |
| :--- | :--- |
| `CSE-Faculty` | Department Admins — Admin access to all repos |
| `DivXX-TYY-Mentors` | Assigned mentors — Admin access to their team's repos only |
| `DivXX-TYY-WorkletZZ` | Students — Push access to their assigned worklet repo only |

## Navigation

- Go to the **Teams** tab to find a specific group.
- Click `Division-01` → `Div01-T01` to browse a team's repos.
- Use the search bar (e.g., type `Div01-T01`) to filter repos directly.

## Adding Members

- **Faculty:** Contact the org admin to be added to `CSE-Faculty`.
- **Students:** Your assigned mentor will add you to your Worklet team.
